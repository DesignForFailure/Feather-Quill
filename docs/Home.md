# Feather Quill

**Feather Quill** is a story outlining and planning tool for writers. Import your existing outlines from Plottr, Markdown, yWriter, or Longform/Obsidian, then export a manuscript, reading copy, or project for another writing app.

> **Note:** Feather Quill is currently in active development. Features and documentation may change.
